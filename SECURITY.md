# Security Policy

## Scope

This repository contains educational security research, lab configurations, automation, and documentation.

## Authorization

Offensive testing is limited to systems I own, isolated laboratory environments, CTF platforms, or systems for which I have explicit permission to test.

## Responsible handling

Do not use project material to access, disrupt, or scan systems without authorization.

Do not publish real secrets, private keys, production credentials, private IP documentation, customer data, or other sensitive information.

## Reporting an issue

For a repository issue that affects the security of the code itself, open a private security report through the repository's supported GitHub security contact mechanism when available.
