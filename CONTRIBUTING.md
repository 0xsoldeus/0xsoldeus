# Contributing

This portfolio favors **reproducible technical evidence** over cosmetic changes.

## Good contributions

- documentation fixes
- reproducible lab improvements
- test coverage
- safer defaults
- clearer diagrams
- detection logic improvements
- protocol parsing correctness

## Before opening a change

- explain the problem
- show how you tested the change
- remove secrets and sensitive data
- state any limitations

## Security boundary

Do not contribute material that targets real systems without authorization.
